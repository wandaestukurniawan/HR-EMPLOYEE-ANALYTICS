# 👥 HR Employee Analytics Dashboard

## 📌 Project Overview
This project presents an interactive **HR Employee Analytics Dashboard** built with **Power BI**. The dashboard provides data-driven insights into workforce demographics, employee performance, retention, and attrition patterns to assist HR teams and management in strategic decision-making.

---

## 📸 Dashboard Preview
![HR Dashboard Preview](assets/dashboard_preview.png)

---

## 🔍 Key Insights & Business Value
* **Workforce Demographics**: Analysis of employee distribution across departments, job roles, and experience levels.
* **Attrition & Retention**: Identification of key factors driving employee turnover.
* **Performance Overview**: Monitoring key HR metrics to optimize workforce management.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop**: Data modeling, DAX measures, and visual report design.
* **Power Query**: Data cleaning, transformation, and shaping.
* **CSV / Excel**: Raw dataset storage.
